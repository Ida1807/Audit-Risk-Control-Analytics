# Audit Risk & Control Analytics
Power BI audit analytics project analysing audit findings, risk, control exceptions and remediation across branches and business processes.
Overview

This project demonstrates the use of Power BI, Power Query and DAX to analyse audit findings, control exceptions, risk ratings and remediation progress across branches and business processes.

The project demonstrates the application of data analytics to support audit risk assessment, control monitoring and management reporting.

Objectives
Analyse audit findings across branches and business processes
Monitor audit completion and audit outcomes
Identify higher-risk control exceptions
Analyse remediation and redressal progress
Identify recurring observations and exception patterns
Provide interactive audit reporting using Power BI
